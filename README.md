# 🏋️‍♀️ MOVA FIT

Projeto web desenvolvido como trabalho da faculdade, focado em persistência de dados, consumo de APIs externas e usabilidade.

## 💻 Sobre o Projeto
O MOVA FIT é uma aplicação web que conta com sistema de cadastro, login, dashboard do usuário, consumo da API ViaCEP para preenchimento automático de endereços e um menu de acessibilidade.

## ✨ Funcionalidades
- Cadastro de usuários com validação de campos.
- Autenticação e login de usuários.
- Persistência de dados locais utilizando `localStorage`.
- Busca e preenchimento de endereço automatizado via API ViaCEP.
- Menu de acessibilidade integrado para melhor experiência do usuário.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação das páginas (`index.html`, `login.html`, `cadastro.html`, etc.).
- **CSS3**: Estilização visual, alinhamentos e responsividade.
- **JavaScript**: Lógica de validação, manipulação do DOM e integração com a API.
